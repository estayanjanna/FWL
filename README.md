# Faculty Workload (FWL)

A Faculty Workload Management System for managing faculty members, courses, teaching assignments, and workload per academic term.

## Planned Features

- Faculty management
- Course and section management
- Teaching assignment management
- Workload dashboard
- User authentication and role management

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM: Prisma
